# EstoquePro

Aplicativo web no formato PWA para controle de estoque.

## Funcionalidades

- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Entrada e saída de estoque
- Alerta de estoque baixo
- Dashboard com resumo do estoque
- Notificações
- Funcionamento offline
- Shortcuts do PWA

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage
- Service Worker
- Web App Manifest

## PWA

O EstoquePro possui:

- `manifest.json`
- Service Worker
- ícones personalizados
- funcionamento offline
- notificações
- atalhos rápidos
